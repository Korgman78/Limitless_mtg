## Le test

Potentiel du pool = score du meilleur build de l'optimizer. Ecart du joueur = potentiel - score du deck joue.
Regression logistique sur les parties : victoire ~ niveau du joueur + potentiel + ecart. Si l'optimizer construit mieux que les joueurs, l'ecart doit faire perdre (coefficient negatif).

| Ressemblance au meilleur des 3 builds (Jaccard), +0.2 | WR 61.8 % -> **62.0 %** | [-0.274 ; +0.332] | pas d'effet distinguable du bruit |

## Limites

- Proxy : Sealed n'est pas ArenaDirect_Sealed (17Lands ne publie pas les parties ArenaDirect).
- Le deck de l'optimizer n'a jamais ete joue : on mesure si s'en ecarter coute des victoires, pas le WR qu'aurait eu son build.
- Le niveau du joueur est un controle grossier ; l'ecart peut aussi refleter le pilotage.
